Least-Squares Regression

หาสมการที่ “ใกล้” ข้อมูลมากที่สุด โดยทำให้ผลรวมกำลังสองของความคลาดเคลื่อน E = Σ [yi − g(xi)]² มีค่าน้อยที่สุด

Linear Regression

ลากเส้นตรง g(x) = a0 + a1x ผ่านข้อมูล n จุด โดยตั้ง ∂E/∂a0 = 0 และ ∂E/∂a1 = 0 แล้วแก้ด้วยกฎของคราเมอร์

a1 = nΣxiyi − ΣxiΣyinΣxi² − (Σxi)²
a0 = ΣyiΣxi² − ΣxiyiΣxinΣxi² − (Σxi)²

ตัวอย่างจากเอกสาร: ความเร็วลม (m/s) ที่ความสูงอาคารต่าง ๆ (m)

Polynomial Regression

ประมาณข้อมูลด้วยพหุนามอันดับ m: g(x) = a0 + a1x + a2x² + … + amxm ได้ระบบสมการ m+1 สมการ ซึ่งสมาชิกแถว r คอลัมน์ c ของเมทริกซ์คือ Σxir+c และด้านขวาคือ Σxiryi

Multiple Linear Regression

เมื่อ y ขึ้นกับหลายตัวแปร y = y(x1, x2, …, xk) สมมติฟังก์ชัน g = a0 + a1x1 + … + akxk แล้วหาค่าต่ำสุดของ E ได้ระบบสมการ k+1 สมการ

กราฟแสดงค่าจริง y เทียบกับค่าที่ประมาณได้ g — ถ้าพอดีจุดจะอยู่บนเส้นทแยง
